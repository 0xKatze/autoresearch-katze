## 1. 「diffusion」是什麼(去神話化)

- **不是 diffusion model**:沒有訓練過的去噪器 εθ、沒有 data prior。
- 實際 = **training-free / 非參數 DDIM 採樣過程**(AdvAD / `DiSGIA-NoParam` 風格):
  bounded linear ᾱ(0.99→0.5, T=20)、predict-x₀、guidance `ε̂ = ε₀ − λ√(1−ᾱ)·s`,λ=2;
  其中 score `s = ∇_{x̂₀}CW` 是**零階 (CGE) 黑盒估**,不是學來的。
- **連續特徵走 DDIM,離散的邊另外用 greedy + k_sweep + 2-swap 搜尋** → 是「拼裝」,不是統一的離散擴散。
- 它是 pipeline 的**最後手段 fallback**:~95% 圖在 5-restart Adam baseline 就解掉,diffusion 只救難尾巴。
- 來源:`attack.py`(`_ddim_step` / `_ddim_predict_x0` / `_make_alpha_schedule_linear` / `_diffusion_restart` / `_attack_joint_diffusion`)、`FINDINGS_N23.md`。

## 3. 「貪婪 cascade 次優嗎?」+「為何還贏 gzoo-katze」

- **會次優,但分軸看**:對 stealth / 擾動大小 / query 效率 / 難尾巴(~13 stuck graphs)次優;對 **raw ASR** 反而高效。
  repo 內證據:2-swap 是為逃 coupled-edge local optima、`node_budget=2` 共享 mask 造成 **−1.85pp**。
- **⚠️ U-E:贏 gzoo-katze 的真因(修正一個常見誤解)**:
  本實驗的 gzoo-katze **根本沒優化邊**(`exp_budget_matched.py` 中三法共用 `attack.py`,邊由 `edge_strategy` 一次選定就固定,restart 只調特徵;**edge_mask 搜尋只在 diffusion 路徑發生**)。
  → diffusion-katze 的 +3pp = **「有做邊搜尋 vs 沒做」**,**不是「貪婪打敗 mutual-info」**。
  → **不能宣稱 diffusion-katze 贏過「真 joint GZOO」**:gzoo-katze 專案的 U3/U4/U5 / dual-generator(真 joint edge 優化)**這次沒跑**。
- **為何 mutual-info 在此 regime 收益小**:mean-pool 把節點平均 → 邊-特徵耦合弱;feat_scale 主導(+62pp);greedy ≠ 搜得少(cascade 的 k_sweep/per-node/restart 反而試更多組態)。
- **⚠️ regime-specific,非普適**:「greedy 較好」只在 PROTEINS-GCN-meanpool-nb1 成立。預期 joint/mutual-info 會反轉的地方:**median-pool 防禦、structure-aware pooling(SAGPool/attention/TopK)、multi-node(`A_ss` 耦合)**。報告裡 median-pool「邊搜尋才 earns its keep(63→92)」已是徵兆。

## 4. 文獻地圖:哪些次優有解、哪裡是空白

- **序列→聯合 (X,A)**:GZOO / CONIA / SpNIA / LiSA / MonTi(one-shot)。
- **貪婪 cascade → 學習式一次生成**:G-NIA / G2A2C / NIPA / MonTi。
- **短視 *引導* → 非貪婪引導**:Universal Guidance(recurrence+backward)、FreeDoM(time-travel)、MPGD/DSG(manifold)、TDS / FK-steering(SMC 粒子群,最對症)、Discrete Guidance、Kerby 2024(離散 training-free)。
- **生成 prior / 隱蔽**:DiGress(離散圖擴散生成器)+ Kerby 2024 → 正規化「拼裝」並天然 on-manifold。

## 5. 下一步候選(把限制變貢獻)

1. **最便宜**:給現有 AMG 加 self-recurrence / time-travel(非貪婪引導,幾乎零設計)。
2. **最對症**:AMG → SMC / FK-steering(粒子群),一次解掉「貪婪 + cascade 早停」,query 可攤在粒子上。
3. **最正規**:DiGress + 免訓練對抗引導(N23-Guided)。⚠️ 需放寬威脅模型(預訓練 → 不再純黑盒,~6h GPU)+ injection-only 改 inpainting。
4. **最該補的對照**:真 joint-edge GZOO-katze(U3/U4/U5)vs diffusion-katze,**在 median-pool / m=2** 下比 — 直接檢驗「joint mutual-info 何時贏」。
