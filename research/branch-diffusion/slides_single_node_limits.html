Single-Node Injection Is Not Enough

A theoretical, empirical, and defense-side case for why graph injection attacks must distribute across multiple nodes.

Branch-Diffusion Team · 2026-05-26

THREAT MODEL

Graph injection adversarial attack

  • 1. Attacker injects K=1+ new nodes into a victim graph; controls injected features X* and edges A*.
  • 2. Goal: flip the graph-level classification while staying below defender's anomaly threshold.
  • 3. Prior work — KATZE, GZOO, SGDI — all default to K=1 (single node).

G' = (V ∪ {v*}, E ∪ {(v*, u) : u ∈ S}, X ∪ {x*})

RESEARCH QUESTION

Does K=1 hit a fundamental ceiling?

  • 1. Theory: Does GCN's normalization create a self-dilution effect at high degree?
  • 2. Experiment: At matched edge budget, does K ≥ 2 beat K=1 on raw ASR?
  • 3. Defense: Can single-node hide from per-node OOD / adjacency denoisers (GDDM-A)?

Three independent angles, one converging answer.

THEORY

GCN self-dilution at high degree

  • 1. Normalized aggregation: Ã = D-1/2 A D-1/2 (symmetric).
  • 2. Per-edge message weight (v*, u) is 1 / √(deg(v*) · deg(u)).
  • 3. As deg(v*) → N, each edge contributes O(1/√N) — the node dilutes its own influence.

DESIGN CHOICE

K=1 single node vs K=3 multi-node

K=1 single node

Simplest threat model. One feature vector, one edge mask.

Self-dilution: more edges → weaker per-edge signal. Degree-N spike triggers per-node anomaly detection.

VS

K=3 multi-node

Distributes edge budget across nodes. Each node degree ≈ clean median; inter-node edges form a sub-community.

More queries to optimize. Need partition strategy + independent per-node feature optimization.

Takeaway: K=1 ceiling exists. Multi-node distributes the degree, restoring per-edge influence and disguising the trojan.

EXPERIMENT 1 — ASR CEILING

K=1 ASR drops when you add edges (signature of self-dilution)

K=1 drops 93.3% → 88.6% as edges double

Adding edges to one node makes EACH edge weaker. K=3 partition delivers +4.8 to +8.4 pp over K=1 (paired).

Caveat: PROTEINS only; ENZYMES multi-node not yet measured.

EXPERIMENT 1 — FULL GRID

Partition strategy + multi-node consistently wins

K=3 partition: 98.1% (best), q/g = 188

partition > duplicate: independent edge masks beat shared edges. Synergy of edge-split + independent feature optimization is essential.

Caveat: cost grows ~2x in queries; manifold (fixed) features show opposite ordering.

EXPERIMENT 2 — DEFENSE VULNERABILITY

Single-node degree-N spike: universally caught by adjacency denoising

SGDI: 0.975 → 0.175 (−80pp)

Even spectrum-preservation (SpecGDI v1) can't save single-node: 0.067. Defender wins regardless of feature/spectral stealth.

Caveat: SpecGDI v1 attack designed for single-node; the failure mode is structural to K=1.

DEFENSE MECHANISM

Per-node anomaly dominates

  • 1. Denoisers and OOD detectors score each node independently.
  • 2. A node of degree N in a graph with median degree ≈ 4 is a 9-15σ outlier on degree alone.
  • 3. No amount of feature or spectral whitening can hide a single-node degree spike from per-node scoring.

z-score(deg(v*)) = (N − μ_deg) / σ_deg ≈ 9 to 15

MITIGATION

K-node trojan with community structure

  • 1. Distribute edge budget across K=3–5 nodes; each node degree ≈ clean median.
  • 2. Add inter-node edges A*VV: trojan looks like a natural sub-community.
  • 3. Caveat: SpecGDI v2 K=3 didn't fully rescue ASR — denoiser scores per-edge, not per-cluster gestalt.

trojan subgraph ≈ (clean community: density, degree, internal spectrum)

5/5 recent GIA stealth papers default to multi-node. KATZE/GZOO/SGDI single-node baselines no longer represent the field.

Caveat: each paper has different K and partition strategy.
